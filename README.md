# Miller Plugins

Claude Code plugins by [Nathan Miller](https://github.com/nmiller0113).

## Install

```
/plugin marketplace add nmiller0113/claude-marketplace
/plugin install kiss@miller-plugins
```

## Plugins

| Plugin | What it does |
| --- | --- |
| [kiss](https://github.com/nmiller0113/kiss) | Deliver exactly what was asked, at the smallest scope that fully satisfies it, then stop and offer more. |
