# Nate's Plugins

Claude Code plugins by [Nate Miller](https://github.com/nmiller0113).

## Install

```
/plugin marketplace add nmiller0113/claude-marketplace
/plugin install kiss@nates-plugins
```

## Plugins

| Plugin | What it does |
| --- | --- |
| [kiss](https://github.com/nmiller0113/kiss) | Deliver exactly what was asked, at the smallest scope that fully satisfies it, then stop and offer more. |
| [fantasy-copilot](https://github.com/nmiller0113/fantasy-copilot) | Fantasy football copilot for Draft Sharks subscribers: live draft-day advising, pre-draft strategy, and season-long weekly guidance. Requires Draft Sharks. |
| [crosscheck](https://github.com/nmiller0113/crosscheck) | Build against the real contract, then send every change for bounded adversarial review: three strikes, roles swap, hard stop at six. |
